# 漫剧AI — Demo 演示项目

纯前端 Mock 数据演示版本，用于商业展示。所有数据均为模拟，无需后端服务。

## 特性

- ✅ 纯 Mock 数据，零后端依赖
- ✅ 自动模拟登录状态
- ✅ 完整的功能页面展示（工作台、分镜、资产、社区、定价等）
- ✅ 模拟 AI 生成进度动画
- ✅ 支持项目增删改查（仅前端内存）
- ✅ 支持素材上传、标签管理（仅前端模拟）
- ✅ 积分充值、钱包管理（仅前端模拟）

## 快速开始

```bash
# 安装依赖
bun install

# 开发模式
bun run dev

# 构建
bun run build

# 预览构建产物
bun run preview
```

开发服务器默认运行在 `http://localhost:4000`

## 页面导航

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `/` | 产品 landing page，展示功能亮点 |
| 工作台 | `/dashboard` | 项目管理、快捷入口 |
| 分镜编辑器 | `/storyboard?projectId=proj-1` | 场景编辑、AI 生成 |
| 资产库 | `/assets` | 角色/背景/道具管理 |
| 社区 | `/gallery` | 作品浏览、筛选、详情 |
| 模型 | `/models` | AI 模型展示 |
| 定价 | `/pricing` | 积分套餐 |
| 钱包 | `/wallet` | 积分余额、交易记录 |
| 个人设置 | `/profile` | 账户信息、API 密钥 |
